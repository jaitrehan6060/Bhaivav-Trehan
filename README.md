# Weather API

A Python project that uses the Open-Meteo API to fetch weather information for a city.

## Features

- Takes a city name as input
- Finds the city's coordinates using the Open-Meteo Geocoding API
- Fetches current weather data
- Displays temperature, humidity, and current time

## Technologies Used

- Python
- Requests
- REST APIs
- Open-Meteo API
